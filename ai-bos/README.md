# AI Business Operating System (AI BOS)

Upload business documents (PDF, DOCX, CSV, XLSX) and ask questions about
them using AI — RAG pipeline over embeddings stored in a vector database,
answers generated by Gemini, backed by source citations.

## Status: Version 1 (MVP) — in progress

Currently built:
- ✅ Project foundation (this zip): backend skeleton, frontend design
  system + app shell, Docker Compose for Postgres + Qdrant
- ⬜ Auth (JWT signup/login/protected routes)
- ⬜ Dashboard
- ⬜ File upload
- ⬜ Document processing (extraction → embeddings → vector store)
- ⬜ AI Chat (RAG)
- ⬜ Analytics
- ⬜ Deployment polish

## Tech Stack

**Frontend:** Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui-style components, Recharts
**Backend:** FastAPI, SQLAlchemy, Alembic, Pydantic
**Database:** PostgreSQL
**Vector DB:** Qdrant
**AI:** LangChain, Gemini API, Sentence Transformers
**Deployment:** Docker Compose

## Project Structure

## Quick Start

```bash
# 1. Backend env
cp backend/.env.example backend/.env
# edit backend/.env: set SECRET_KEY (openssl rand -hex 32) and GEMINI_API_KEY

# 2. Frontend env
cp frontend/.env.example frontend/.env

# 3. Run everything
docker compose up --build
```

Then check:
- Frontend: http://localhost:3000
- Backend health: http://localhost:8000/api/v1/health
- API docs: http://localhost:8000/docs
- Qdrant dashboard: http://localhost:6333/dashboard

## Running frontend or backend standalone (without Docker)

**Backend:**
```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```

## Architecture Notes

Backend follows a strict one-direction dependency chain:

```
Request → API Router → Service (business logic) → Repository (DB access) → Model
```

- Routers never touch SQL directly.
- Services hold business logic, no HTTP awareness.
- Repositories are the only layer touching the DB session.
- Pydantic schemas are strictly for request/response validation — never used as DB models.

This keeps each layer independently testable and easy to extend as
Version 2 features (multi-agent system, RBAC, etc.) are added later.
